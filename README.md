# ฐานข้อมูลอาหารไทยและคุณค่าทางโภชนาการ

ระบบฐานข้อมูลอาหารไทยแบบครบครันที่รวมการค้นหาสูตรอาหาร การวิเคราะห์คุณค่าทางโภชนาการ และการแนะนำอาหารตามความต้องการ

## ✨ คุณสมบัติหลัก (Main Features)

### 🔍 การค้นหาและถามตอบ
- ค้นหาสูตรอาหารไทยด้วยการพิมพ์คำถามหรือชื่ออาหาร
- ระบบ AI ที่เข้าใจภาษาไทยและภาษาอังกฤษ
- การค้นหาแบบ semantic search ด้วย sentence transformers
- การค้นหาแบบความคล้ายคลึงของข้อความ
- รองรับการถามเกี่ยวกับคุณค่าทางโภชนาการ (เช่น "อาหารโปรตีนสูง", "อาหารแคลอรี่ต่ำ")

### 📊 การวิเคราะห์คุณค่าทางโภชนาการ
- คำนวณคุณค่าทางโภชนาการอัตโนมัติจากรายการวัตถุดิบ
- ระบบประมาณน้ำหนักวัตถุดิบที่ฉลาด
- แสดงข้อมูล: แคลอรี่, โปรตีน, ไขมัน, คาร์โบไฮเดรต, ใยอาหาร
- วิตามินและแร่ธาตุ: แคลเซียม, เหล็ก, วิตามิน C, วิตามิน A
- กราฟแสดงสัดส่วนสารอาหารหลัก
- รายละเอียดโภชนาการของแต่ละวัตถุดิบ

### 🍽️ การแนะนำอาหาร
- แนะนำอาหารตามเงื่อนไขคุณค่าทางโภชนาการ
- กรองอาหารตามระดับแคลอรี่, โปรตีน, ไขมัน, ใยอาหาร, แคลเซียม
- จัดอันดับความเหมาะสมตามเกณฑ์ที่เลือก

### ⚙️ แถบการตั้งค่าขั้นสูง
- ดาวน์โหลดข้อมูลโภชนาการจาก USDA API
- บันทึกข้อมูลโภชนาการเป็นไฟล์ CSV
- ตั้งค่าการคำนวณแบบการบริโภคจริง (cooking adjustment)
- เปิด/ปิดการแสดงรายละเอียดวิตามินและแร่ธาตุ

## 🚀 การติดตั้งและใช้งาน

### ความต้องการระบบ
- Python 3.8 หรือใหม่กว่า
- RAM อย่างน้อย 4GB (แนะนำ 8GB)
- พื้นที่ว่างในฮาร์ดดิสก์ 2GB

### การติดตั้ง

1. **โคลนโปรเจค**
```bash
git clone https://github.com/yourusername/thai-food-nutrition-database.git
cd thai-food-nutrition-database
```

2. **สร้าง Virtual Environment**
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS/Linux
python -m venv venv
source venv/bin/activate
```

3. **ติดตั้ง Dependencies**
```bash
pip install -r requirements.txt
```

4. **ตรวจสอบไฟล์ข้อมูล**
ให้แน่ใจว่าไฟล์ `thai_food_processed.csv` อยู่ในโฟลเดอร์โปรเจค

### การเริ่มต้นใช้งาน

```bash
streamlit run streamlit_app.py
```

จากนั้นเปิดเว็บเบราว์เซอร์และไปที่ `http://localhost:8501`

## 📋 การใช้งานแต่ละฟีเจอร์

### 1. การค้นหาสูตรอาหาร

**ตัวอย่างคำค้นหา:**
- `ผัดไทย` - ค้นหาสูตรผัดไทย
- `อาหารโปรตีนสูง` - ค้นหาอาหารที่มีโปรตีนสูง
- `อาหารแคลอรี่ต่ำ` - ค้นหาอาหารแคลอรี่ต่ำ
- `อาหารมีแคลเซียมเยอะ` - ค้นหาอาหารที่มีแคลเซียมสูง
- `ทำกับไก่` - ค้นหาอาหารที่ใช้ไก่เป็นวัตถุดิบ

### 2. การใช้งาน USDA API

1. สมัคร API Key ฟรีจาก [USDA FoodData Central](https://fdc.nal.usda.gov/api-guide.html)
2. เปิดแถบการตั้งค่าด้านซ้าย
3. ป้อน API Key ในช่อง "USDA API Key"
4. เลือกจำนวนข้อมูลที่ต้องการดาวน์โหลด
5. คลิก "ดาวน์โหลดข้อมูล USDA"

### 3. การปรับปรุงข้อมูลด้วย Preprocessing

```bash
# ประมวลผลข้อมูลใหม่
python preprocess.py --input thai_food_raw.csv --output thai_food_processed.csv

# วิเคราะห์ข้อมูลหลังประมวลผล
python preprocess.py --input thai_food_raw.csv --output thai_food_processed.csv --analyze
```

## 🔧 ฟีเจอร์การปรับปรุงข้อมูลอัตโนมัติ

### การประมาณปริมาณวัตถุดิบ
- แยกตัวเลข หน่วยวัด และชื่อวัตถุดิบอัตโนมัติ
- มาตรฐานหน่วยวัด (กรัม, ช้อนโต๊ะ, ช้อนชา, ถ้วย, ตัว, ฟอง, ฯลฯ)
- ประมาณปริมาณเมื่อไม่ระบุหน่วย
- ตรวจสอบและแก้ไขปริมาณที่ไม่สมเหตุสมผล

### การคำนวณโภชนาการแบบการบริโภคจริง
- น้ำมันทอด: คำนวณเฉพาะส่วนที่ดูดซึม (15% ของปริมาณที่ใช้)
- เครื่องปรุงรส: ปรับลดปริมาณเมื่อใช้มากเกินจริง
- วัตถุดิบที่ใช้เพื่อการปรุงแต่ไม่บริโภคทั้งหมด

## 📊 ข้อมูลโภชนาการที่รองรับ

### สารอาหารหลัก
- **แคลอรี่** (kcal)
- **โปรตีน** (g)
- **ไขมัน** (g)
- **คาร์โบไฮเดรต** (g)
- **ใยอาหาร** (g)

### วิตามินและแร่ธาตุ
- **แคลเซียม** (mg)
- **เหล็ก** (mg)
- **วิตามิน C** (mg)
- **วิตามิน A** (µg)

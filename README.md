# แชทบอทสูตรอาหารไทยพร้อมข้อมูลคุณค่าทางโภชนาการ

ระบบแชทบอทอัจฉริยะสำหรับค้นหาและวิเคราะห์สูตรอาหารไทย พร้อมข้อมูลคุณค่าทางโภชนาการที่ครอบคลุม

## ✨ คุณสมบัติใหม่

### 🍎 การวิเคราะห์คุณค่าทางโภชนาการ
- **วิเคราะห์อัตโนมัติ**: ระบบสามารถวิเคราะห์คุณค่าทางโภชนาการของวัตถุดิบแต่ละชนิดได้อัตโนมัติ
- **ข้อมูลครอบคลุม**: รวมข้อมูลพลังงาน โปรตีน คาร์โบไฮเดรต ไขมัน วิตามิน และแร่ธาตุ
- **แหล่งข้อมูลเชื่อถือได้**: ใช้ข้อมูลจาก USDA FoodData Central
- **การแสดงผลที่สวยงาม**: กราฟและตารางแสดงข้อมูลคุณค่าทางโภชนาการ

### 🔍 การค้นหาขั้นสูง
- **ค้นหาตามคุณค่าทางโภชนาการ**: กรองเมนูตามพลังงาน โปรตีน ไขมัน หรือวิตามิน
- **ตัวกรองที่หลากหลาย**: ปรับแต่งการค้นหาตามความต้องการด้านโภชนาการ
- **คำแนะนำอัจฉริยะ**: ระบบแนะนำเมนูที่เหมาะกับเป้าหมายด้านสุขภาพ

## 🚀 การติดตั้งและใช้งาน

### 1. ติดตั้งแพ็คเกจที่จำเป็น

```bash
pip install -r requirements.txt
```

### 2. ตั้งค่า API Key สำหรับข้อมูลคุณค่าทางโภชนาการ

สมัครสำหรับ USDA FoodData Central API key (ฟรี) ที่:
https://fdc.nal.usda.gov/api-guide.html

จากนั้นตั้งค่า environment variable:

```bash
# Windows
set USDA_API_KEY=your_api_key_here

# macOS/Linux
export USDA_API_KEY=your_api_key_here
```

หรือสร้างไฟล์ `.env` ในโฟลเดอร์โปรเจค:
```
USDA_API_KEY=your_api_key_here
```

### 3. เริ่มต้นใช้งาน

```bash
streamlit run streamlit_app.py
```

## 📊 การวิเคราะห์คุณค่าทางโภชนาการ

### การใช้งานระบบวิเคราะห์

1. **ผ่านหน้าเว็บ**: คลิกปุ่ม "🔍 วิเคราะห์คุณค่าทางโภชนาการ" ในแถบข้าง
2. **ผ่าน Python script**:

```python
from nutrition_analyzer import NutritionAnalyzer

# สร้างตัววิเคราะห์
analyzer = NutritionAnalyzer(api_key="your_usda_api_key")

# วิเคราะห์ไฟล์ CSV
analyzer.process_csv_file("thai_food_processed.csv", "thai_food_with_nutrition.csv")
```

### ข้อมูลที่วิเคราะห์ได้

- **สารอาหารหลัก**: พลังงาน โปรตีน คาร์โบไฮเดรต ไขมัน ใยอาหาร
- **แร่ธาตุ**: แคลเซียม เหล็ก ฟอสฟอรัส แมกนีเซียม สังกะสี โพแทสเซียม
- **วิตามิน**: A, C, D, E, K, B1, B2, B3, B6, B12, โฟเลต

## 🔍 ตัวอย่างการใช้งาน

### การค้นหาแบบดั้งเดิม
```
"ต้มยำกุ้ง"
"แกงเขียวหวาน"
"ผัดไทย"
```

### การค้นหาตามคุณค่าทางโภชนาการ
```
"อาหารที่มีโปรตีนสูง"
"เมนูแคลอรี่ต่ำ"
"อาหารอุดมไปด้วยวิตามิน C"
"อาหารสำหรับผู้ป่วยเบาหวาน"
```

### การใช้ตัวกรอง
- **พลังงานสูงสุด**: กำหนดแคลอรี่สูงสุดที่ต้องการ
- **โปรตีนต่ำสุด**: กำหนดปริมาณโปรตีนขั้นต่ำ
- **ไขมันสูงสุด**: จำกัดปริมาณไขมัน
- **อุดมด้วยวิตามิน C**: แสดงเฉพาะเมนูที่มีวิตามิน C สูง

## 🧠 เทคโนโลยีที่ใช้

### ระบบแชทบอท
- **Sentence Transformers**: สำหรับการเข้ารหัสและค้นหาความหมาย
- **Streamlit**: สำหรับสร้างหน้าเว็บแอปพลิเคชัน
- **Scikit-learn**: สำหรับคำนวณความคล้ายคลึง

### ระบบวิเคราะห์คุณค่าทางโภชนาการ
- **USDA FoodData Central API**: แหล่งข้อมูลคุณค่าทางโภชนาการ
- **Plotly**: สำหรับสร้างกราฟและการแสดงผล
- **Pandas**: สำหรับการจัดการข้อมูล

## 📈 การแสดงผลข้อมูล

### กราฟและตาราง
- **กราฟวงกลม**: แสดงสัดส่วนสารอาหารหลัก
- **การ์ดข้อมูล**: แสดงคุณค่าทางโภชนาการในรูปแบบที่อ่านง่าย
- **ตัวชี้วัด**: แสดงสถิติสรุปของข้อมูล

### ความสามารถในการปรับแต่ง
- **เปลี่ยนหน่วยการแสดงผล**: ต่อ 100 กรัม หรือต่อหนึ่งเสิร์ฟ
- **เปรียบเทียบเมนู**: เปรียบเทียบคุณค่าทางโภชนาการระหว่างเมนูต่างๆ
- **ส่งออกข้อมูล**: บันทึกข้อมูลคุณค่าทางโภชนาการเป็นไฟล์ CSV

## 🔧 การพัฒนาและปรับแต่ง

### การเพิ่มวัตถุดิบใหม่
1. เพิ่มชื่อวัตถุดิบในพจนานุกรมแปลภาษา (`thai_to_english`)
2. ระบบจะวิเคราะห์คุณค่าทางโภชนาการอัตโนมัติ
3. ข้อมูลจะถูกบันทึกใน cache เพื่อความเร็วในการเข้าถึงครั้งต่อไป

### การปรับปรุงข้อมูล
- อัปเดตข้อมูลคุณค่าทางโภชนาการ: รันคำสั่งวิเคราะห์ใหม่
- เพิ่มสูตรอาหารใหม่: อัปเดตไฟล์ CSV และลบไฟล์ `embeddings.pkl`

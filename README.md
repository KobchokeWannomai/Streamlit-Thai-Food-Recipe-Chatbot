4. ไปที่แถบการตั้งค่าในแอป เปิดใช้งาน Nutritionix API และใส่ข้อมูล

## 🧪 ตัวอย่างการใช้งานขั้นสูง

### การวิเคราะห์โภชนาการแบบ Programmatic

```python
from nutrition_analyzer import NutritionAnalyzer

# สร้าง analyzer พร้อม API integration
analyzer = NutritionAnalyzer(
    usda_api_key="your_api_key",
    nutritionix_app_id="your_app_id",
    nutritionix_api_key="your_api_key"
)

# วิเคราะห์ด้วยการปรับแต่งการทำอาหาร
ingredients = """
- ไข่ไก่ 2 ฟอง
- น้ำมันพืช 3 ช้อนโต๊ะ (สำหรับทอด)
"""

nutrition_data = analyzer.analyze_ingredients(
    ingredients, 
    recipe_name="ไข่เจียว",
    apply_cooking_adjustments=True
)

total = analyzer.calculate_total_nutrition(nutrition_data)
print(f"แคลอรี่รวม (ปรับแล้ว): {total.calories:.0f} kcal")
```

3. **เปิดใช้ฟีเจอร์ขั้นสูง**:

## USDA FoodData Central API (ฟรี)

### 🌟 ทำไมต้องเลือก USDA API?

- ✅ **ฟรีสมบูรณ์** ไม่มีขีดจำกัดการใช้งาน
- ✅ **รองรับโดยรัฐบาล** ข้อมูลโภชนาการที่เชื่อถือได้
- ✅ **ฐานข้อมูลครอบคลุม** อาหารมากกว่า 300,000 รายการ
- ✅ **ครอบคลุมสากล** รวมอาหารเอเชีย
- ✅ **ไม่ต้องบัตรเครดิต**
- ✅ **เปิดใช้งานทันที**

### 📝 การตั้งค่าทีละขั้น

#### 1. เยี่ยมชมเว็บไซต์ USDA
```
🔗 https://fdc.nal.usda.gov/api-guide.html
```

#### 2. ขอ API Key
1. คลิกปุ่ม **"Get an API Key"**
2. กรอกแบบฟอร์มลงทะเบียน:

```
ชื่อ: [ชื่อเต็มของคุณ]
อีเมล: [ที่อยู่อีเมลของคุณ]
องค์กร: การใช้งานส่วนตัว (หรือบริษัทของคุณ)
วัตถุประสงค์: การวิเคราะห์โภชนาการสูตรอาหารสำหรับแชทบอทอาหารไทย
```

#### 3. ยืนยันอีเมล
- ตรวจสอบกล่องจดหมายของคุณ
- คลิกลิงก์ยืนยัน
- API key จะถูกส่งไปยังอีเมลของคุณ

#### 4. ตัวอย่างการตอบกลับทางอีเมล
```
หัวข้อ: Your FoodData Central API Key

เรียน [ชื่อของคุณ],

API Key ของคุณ: abcd1234-5678-90ef-ghij-klmnopqrstuv

เอกสาร API: https://fdc.nal.usda.gov/api-guide.html
ขีดจำกัดอัตรา: ไม่มีขีดจำกัดสำหรับการใช้งานสาธารณะ
```

#### 5. ทดสอบ API Key ของคุณ
```bash
curl "https://api.nal.usda.gov/fdc/v1/foods/search?api_key=YOUR_API_KEY&query=banana&pageSize=1"
```

การตอบสนองที่คาดหวัง:
```json
{
  "totalHits": 1234,
  "currentPage": 1,
  "totalPages": 1234,
  "foods": [...]
}
```

## Nutritionix API (พรีเมียม)

### 🥇 ทำไมควรพิจารณา Nutritionix?

- ✅ **คำสั่งภาษาธรรมชาติ** ("1 ถ้วย ข้าวสุก")
- ✅ **ฐานข้อมูลอาหารแบรนด์** (ร้านอาหาร, อาหารบรรจุ)
- ✅ **การวิเคราะห์สูตรอาหาร** พร้อมการจดจำวัตถุดิบอัตโนมัติ
- ✅ **200 requests ฟรี/วัน** (เพียงพอสำหรับการใช้งานส่วนตัว)
- ⚠️ **แผนแบบเสียเงิน** สำหรับการใช้งานสูงกว่า

### 📝 การตั้งค่าทีละขั้น

#### 1. สร้างบัญชี
```
🔗 https://www.nutritionix.com/business/api
```

#### 2. เลือกแผน
- **แผนฟรี**: 200 requests/วัน
- **แผนพื้นฐาน**: $49/เดือน สำหรับ 5,000 requests/วัน
- **แผนโปร**: $299/เดือน สำหรับ 50,000 requests/วัน

#### 3. รับ API Credentials
หลังจากสมัครสมาชิก คุณจะได้รับ:
```
Application ID: 12345678
Application Key: abcdef1234567890abcdef1234567890
```

#### 4. ทดสอบ Credentials ของคุณ
```bash
curl -X POST \
  https://trackapi.nutritionix.com/v2/natural/nutrients \
  -H 'Content-Type: application/json' \
  -H 'x-app-id: YOUR_APP_ID' \
  -H 'x-app-key: YOUR_APP_KEY' \
  -d '{"query": "1 cup rice"}'
```

## การตั้งค่าในแอป

### 🖥️ การใช้แถบการตั้งค่า

#### 1. เริ่มแอป
```bash
streamlit run streamlit_app.py
```

#### 2. เปิดการตั้งค่า
- มองหาปุ่ม **⚙️ การตั้งค่า** ในแถบด้านซ้าย
- คลิกเพื่อขยายแผงการตั้งค่า

#### 3. ส่วนการกำหนดค่า API

**สำหรับ USDA API:**
1. ✅ เช็ค "เปิดใช้งาน USDA API"
2. 📝 วาง API key ของคุณในช่องข้อความ
3. 🔍 คลิก "ทดสอบการเชื่อมต่อ"
4. ✅ มองหาตัวบ่งชี้สถานะสีเขียว

**สำหรับ Nutritionix API:**
1. ✅ เช็ค "เปิดใช้งาน Nutritionix API"
2. 📝 ใส่ App ID ของคุณ
3. 📝 ใส่ API Key ของคุณ
4. 🔍 คลิก "ทดสอบการเชื่อมต่อ"
5. ✅ มองหาตัวบ่งชี้สถานะสีเขียว

#### 4. ฟีเจอร์ขั้นสูง
เปิดใช้สิ่งเหล่านี้สำหรับการทำงานที่ปรับปรุงแล้ว:
- ✅ **ใช้ข้อมูลสูตรอาหารภายนอก** - การคำนวณการทำอาหารที่ปรับปรุงแล้ว
- ✅ **การคำนวณการทำอาหารที่แม่นยำ** - การดูดซึมน้ำมัน, การสูญเสียน้ำ
- ✅ **ขอบเขตการค้นหาที่ปรับปรุงแล้ว** - ผลการค้นหาที่ดีกว่า

### 🔧 การใช้ Environment Variables (ไฟล์ .env)

#### 1. คัดลอกไฟล์ตัวอย่าง
```bash
cp .env.example .env
```

#### 2. แก้ไขไฟล์ .env
```bash
# API Keys
USDA_API_KEY=your_actual_usda_api_key_here
NUTRITIONIX_API_KEY=your_actual_nutritionix_api_key_here
NUTRITIONIX_APP_ID=your_actual_nutritionix_app_id_here

# เปิดใช้ฟีเจอร์
ENABLE_API_INTEGRATION=true
ENABLE_ENHANCED_SEARCH=true
ENABLE_COOKING_ADJUSTMENTS=true
```

#### 3. รีสตาร์ทแอป
```bash
# หยุดแอป (Ctrl+C)
# เริ่มใหม่
streamlit run streamlit_app.py
```

## การแก้ไขปัญหา

### 🔴 ปัญหาทั่วไปและการแก้ไข

#### ปัญหา: "การเชื่อมต่อ API ล้มเหลว"
**สาเหตุที่เป็นไปได้:**
- API key ไม่ถูกต้อง
- ปัญหาการเชื่อมต่อเครือข่าย
- บริการ API ล่มชั่วคราว
- เกินขีดจำกัดอัตรา

**วิธีแก้:**
1. ตรวจสอบการสะกด API key อีกครั้ง
2. ทดสอบด้วยคำสั่ง curl
3. ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต
4. รอสักครู่และลองใหม่

#### ปัญหา: "เกินขีดจำกัดอัตรา"
**สำหรับ USDA**: ไม่มีขีดจำกัดอัตรา, นี่ไม่ควรเกิดขึ้น
**สำหรับ Nutritionix**: คุณเกินขีดจำกัดรายวัน

**วิธีแก้:**
1. รอจนถึงวันถัดไป (สำหรับแผนฟรี)
2. อัปเกรดเป็นแผนแบบเสียเงิน
3. ใช้ USDA API เป็นแหล่งหลัก

#### ปัญหา: "ไม่พบข้อมูล"
**สาเหตุที่เป็นไปได้:**
- API key ไม่ได้กำหนดค่า
- วัตถุดิบไม่อยู่ในฐานข้อมูล
- พิมพ์ชื่อวัตถุดิบผิด

**วิธีแก้:**
1. ตรวจสอบการกำหนดค่า API ในการตั้งค่า
2. ลองชื่อวัตถุดิบทางเลือก
3. ใช้ฐานข้อมูลไทยในตัวเป็นตัวสำรอง
